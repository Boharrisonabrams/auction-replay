## What this changes about the product

The core is a **league-specific valuation calculation**. It should estimate the incremental starting-lineup production a purchase buys, given this league’s scoring, keepers, remaining talent, budgets, and likely prices. A roster comparison then makes that calculation understandable.

The first benchmark is to revisit the actual auction decisions above using information available on September 3, 2025. Compare a reference-price policy, a league-inflation policy, and an approach that values complete roster alternatives. Identify the bid prices at which recommendations change. Vary subsequent sale prices and opponent responses; the historical prices cannot be assumed to remain fixed after a different bid.

Before claiming draft-time advantage, recover the original reference values or projections and weekly results through Week 17. Evaluate points from a legal starting lineup, the cost of its alternatives, sensitivity to injuries and performance assumptions, and how much of the effect survives outside this one season. Simple points per dollar can favor cheap bench depth while missing the value of scarce starting slots.

The 2026 league is a separate Yahoo league and currently lists an offline draft, whereas the archived 2025 league lists a live salary-cap draft. The intended upcoming draft venue remains to be established before choosing the live input flow.
